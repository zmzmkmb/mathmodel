# 模型选择决策指南

拿到问题后，按以下决策树选择模型。选择模型时优先用简单方法，视性能再逐步升级。

---

## 预测类（要预测未来数值）

- 有多个影响因素 → 回归模型（线性/Ridge/Lasso/XGBoost）
- 只有时间序列 → ARIMA / Prophet / 指数平滑 / LSTM
- 数据很少 (<15 个) → 灰色预测 GM(1,1)
- 非线性很强 → 随机森林 / XGBoost / GBDT
- 需要不确定性估计 → MCMC / Bootstrap

## 评价决策类（要评价/排序/选方案）

- 需要定权重 → AHP（主观）/ 熵权法（客观）
- 方案排序 → TOPSIS / PCA-TOPSIS
- 指标模糊 → 模糊综合评价
- 评价效率 → DEA

## 分类聚类类（要分类/分群）

- 有标签 → 随机森林 / SVM / 决策树 / Logistic 回归
- 无标签 → K-means / 层次聚类 / DBSCAN

## 优化类（求最大/最小）

- 线性约束 → 线性规划
- 非线性/复杂 → 遗传算法 / 模拟退火 / 数值网格搜索
- 多目标冲突 → NSGA-II / 加权和法
- 序贯决策 → 动态规划

## 统计分析类（分析变量关系）

- 两变量相关 → Pearson / Spearman 相关分析
- 多组比较 → 方差分析 ANOVA / t 检验
- 特征重要性 → SHAP 值分析 / 特征重要性排序

## 文本分析类

- 情感分析 → VADER / TextBlob / BERT
- 主题提取 → LDA / TF-IDF

## 仿真类（模拟系统演化）

- 不确定性/风险 → 蒙特卡洛模拟
- 空间扩散/演化 → 元胞自动机
- 风险度量 → CVaR / VaR

# 常见高分组合方案

| 问题类型 | 推荐组合 | 说明 |
|---------|---------|------|
| 综合评价 | AHP + TOPSIS | AHP 定权重，TOPSIS 排序 |
| 预测+不确定性 | XGBoost + Bootstrap/MCMC | 预测 + 置信区间 |
| 方案优选 | AHP + 熵权法 + TOPSIS | 主客观结合更有说服力 |
| 风险评估 | Logistic 回归 + 蒙特卡洛 | 概率 + 模拟 |
| 文本分析 | TF-IDF + LDA + 情感分析 | 特征提取 + 主题 + 情感 |
| 时空预测 | ARIMA/LSTM + 空间聚类 | 时间 + 空间维度 |
| 投资优化 | 预测模型 + 动态规划/遗传算法 | 预测 + 优化 |
| 效应分析 | DID/回归 + SHAP 值分析 | 因果 + 解释 |

创新体现在问题适配性而非算法复杂度。优先用简单模型解决核心问题。

# 工程优化铁律（极易被扣分）

优化绝不能只追求数学极值，必须考虑物理可行性。常见致命错误：

- 模型是缩尺桌面模型（高度仅几百 mm），优化结果却给出数米长的构件——物理上根本放不下
- 盲目追求目标函数最小化，忽略了设计变量的几何/物理边界

**每个优化变量必须有物理上界和下界**。例如绳长 L 受限于模型离地高度，不得超过 500mm。
在方案中明确写出：

> 无约束解为 XX，但违反物理限制，因此引入约束 XX ≤ XX_max，约束下的解为 YY。

评委看到这种工程思维分析会给高分。
