## 文件处理规则

1. 所有数据文件已预上传到工作目录，直接使用相对路径读取
2. 不要检查文件是否存在——假设文件已就绪
3. Excel 文件：始终使用 `pd.read_excel()`
4. 智能编码检测：先试 utf-8，再试 gbk, gb2312, latin-1

## 大文件处理协议

对于 >1GB 的数据集：
- 使用 `chunksize` 参数配合 `pd.read_csv()`
- 导入时优化 dtype（如 `dtype={'id': 'int32'}`）
- 指定 `low_memory=False`
- 字符串列使用 categorical 类型
- 分批处理数据
- 及时删除中间对象

## 数据预处理规范（按问题类型区分）

### 先判断题目类型

- **物理/力学机理题**（参数为给定常量，如 H=200mm, m=3kg）：
  不要画直方图、箱线图或提"异常值清洗""缺失值"。
  EDA 聚焦于：打印关键参数表格 → 几何关系计算 → 量纲验证 → 物理一致性检查。

- **数据驱动题**（有真实数据集、多样本）：
  执行完整 EDA 流程。

### 数据驱动题的 EDA 必须覆盖

1. `.info()` 和 `.head()` 查看数据结构
2. 缺失值报告：列出缺失数、缺失率、填充策略及理由
3. 异常值检测：IQR 或 Z-score，报告异常占比
4. 数据分布可视化：直方图/箱线图
5. 变量相关性分析：热力图
6. 分组对比分析

## 数据泄露防范（关键！）

- 时序特征：用 `shift(1)` 获取上一期，**禁止** `shift(-1)`
- 滚动特征：`rolling(w).mean().shift(1)` 排除当期
- 标准化：只用训练集 fit，测试集 transform
- 目标编码：只用训练集计算统计值
- 时序问题不能随机打乱数据再划分

## 特征工程

- 滞后特征用 `shift(1)` 避免泄露
- 滚动窗口特征带 `shift(1)` 排除当期
- 分类变量用 One-Hot 或 Label Encoding
- 右偏分布考虑对数变换 `np.log1p()`

## 可视化规范

### 预配置变量（沙盒已注入，直接使用）

- `CJK_FONT` — 中文字体
- `COLORS` — 统一配色字典
- `FIG_SINGLE`, `FIG_DOUBLE`, `FIG_WIDE`, `FIG_SQUARE` — 标准图尺寸

```python
fig, ax = plt.subplots(figsize=FIG_SINGLE)
sns.lineplot(x=x, y=y, ax=ax, color=COLORS['primary'])
```

### 禁止项

- 3D图表（除非展示真3D数据）
- 饼图（改用水平条形图）
- 图表内大标题（用论文 caption）
- 密集网格线
- 四边完整边框（只保留左+下）
- 低分辨率输出

### 必须项

- 去掉上右边框
- 使用统一 COLORS 配色
- 折线图用 `fill_between` 添加置信带
- 标注关键统计量（r, p, R²）
- 子图编号用 (a), (b), (c)
- 图例无边框
- 清晰的轴标签（含单位）
- 参考线标注（如基线、阈值）
- 300dpi 输出

## 优化类工程约束

- **每个优化变量必须有物理上界和下界**
- 在 print 中对比无约束解与约束解
- 常见错误：桌面缩尺模型优化结果给出数米长构件；绳长 L 超过模型高度；转速设为 0

## 性能关键

- 优先使用向量化操作而非循环
- 稀疏数据使用 csr_matrix
- 及时释放不用资源
- 大文件分批读取

## 执行原则

1. 自主完成任务，不要询问用户确认
2. 遇到失败：分析 → 调试 → 简化方法 → 继续，不要陷入死循环
3. 保持与用户输入一致的语言
4. 在关键阶段通过可视化记录过程
5. 完成前验证：所有要求的输出已生成，文件已正确保存
