# 建模知识库分层

运行时知识库按职责分为三层，不再把所有记录作为同一种“相似论文”返回。

## 1. 证据案例层

- 主来源：同级已授权 `math-modeling-skill-pro/cases/`。
- 当前规模：139 张案例卡，对应 138 个来源论文标题。
- 与本地条目同源时，把本地模型、验证和可视化细节并入案例卡。
- 必须保留来源页、证据模式、适用边界和可迁移规律。

## 2. 方法卡层

- 来源：`data/modeling.yaml` 中未与 Pro 案例同源的本地记录。
- 当前规模：225 条。
- 用途：提供候选模型、求解链、验证方法、可视化和常见失败模式。
- 证据等级低于 Pro 案例，不得仅凭出现频次宣称某模型更优。

## 3. 规则与验证层

- 规则来源：专题知识文档、工作流门禁和模型选择规范。
- 验证要求由子问题软画像组合生成。
- 机理、数据、优化分数只负责选择工具，不是硬性题型标签。

## 检索契约

一次画像检索应组合返回：

1. 2-3 张可追溯证据案例；
2. 1-3 张本地方法卡；
3. 与画像匹配的验证要求；
4. 必要的专题规则。

硬门禁只有数据可追溯、推导完整、实现一致、验证充分和结论真实，不包括 B/C 二选一。
